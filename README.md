# 🚔 교통수첩 T-Book

**교통외근 통합보조 — 외우지 말고, 필요할 때 펼쳐 보는 핸드북**
*T-Book — a field handbook for traffic police*

단일 HTML 파일 PWA. 모든 데이터는 **본인 기기 안에서만** 처리되며 외부 전송이 없습니다.

- 현재 배포 버전: **v21.66** (2026 전국 공용판)
- 법령·범칙금 기준일: **2026.7** — 앱 화면 상단 배지에 항상 표시됩니다
- 판례 **43건** / 판결문 원문 **36건** · 화면 **69개**(탭으로 여는 화면 47개)

## 🔐 자료 보호 구조

이 저장소는 GitHub Pages 배포를 위해 **공개(public)** 로 운영됩니다.
자료 보호는 저장소 접근 제한이 아니라 **앱 내부 구조**로 구현되어 있습니다.

| 구분 | 처리 방식 |
|---|---|
| 법령·조문·판례 등 **공개 정보** | 평문 수록 (국가법령정보센터 등 공개 출처 원문 대조) |
| **직무 관련 상세 매뉴얼** | **AES-256-GCM** 암호화 상태로 파일에 내장. 복호화는 인가된 사용자가 **기기 안에서** 수행 |
| 진입 인증 | 정답을 **SHA-256 해시로만** 코드에 보관. 5회 오답 시 1시간 잠금 — 다만 **바른 코드는 잠금 중에도 통과**합니다(v21.66). 한/영 전환을 안 한 영문 자판 입력도 같이 받습니다 |
| **외부 전송** | 서버·DB·외부 API 호출 **없음. 통신 0건** — CSP `connect-src 'none'` 으로 코드 수준에서 차단 |
| 개인정보 자동 삭제 | 입력란에 개인정보가 감지되면 **8시간 경과 시 자동 소거**, 백그라운드 60분 경과 시에도 소거 |
| 주민등록번호 | **저장 자체를 거부**합니다. 서류 작성란의 예시도 **마스킹**(`800101-1******`)이며 **브라우저 자동완성을 차단**합니다. 차량번호·전화번호는 경고를 띄웁니다 |
| 사용 기한 | **2027-02-20 자동 만료 → 화면 잠금.** 데이터는 보존되며, 잠금 화면에서 ①전량 백업 ②해제코드로 365일 연장 ③수동 삭제 중 선택 |

`robots.txt` 로 검색엔진 수집을 차단하고 있습니다.

### 입력란에 대한 정확한 설명

이 앱에는 **입력란이 있습니다** — 교대근무표·시간외수당 계산, 현장 관찰 메모,
내 서식·공문함(PDF·한글·워드·엑셀 첨부) 등이 입력을 받습니다.

**핵심은 「입력란이 없다」가 아니라 「입력한 것이 기기 밖으로 나가지 않는다」입니다.**

- 입력값은 전부 해당 기기의 `localStorage` / `IndexedDB` 에만 저장됩니다
- 서버로 보내는 코드가 **존재하지 않으며**, CSP `connect-src 'none'` 으로 통신 자체가 막혀 있습니다
- **현장 관찰 기록 창구에는 성명·차량번호·사진 입력란을 두지 않았습니다**
- **내 서식·공문함은 서식·공문 보관용**이며, 사건 자료 반입은 경고로 차단합니다
- 개인정보가 입력되면 **설정된 시간(기본 8시간) 경과 시 자동 삭제**됩니다

> 이전 README에 「입력 필드 0개」라고 적혀 있었으나 **사실과 달라 정정했습니다.**
> 실제로는 `input` 189개 · `textarea` 22개 · `select` 41개가 있습니다.
> 이 앱의 강점은 입력을 막는 것이 아니라 **입력한 것을 내보내지 않는 것**입니다.

## 📁 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | **앱 본체.** 이 파일 하나만 교체하면 업데이트 완료 |
| `go.html` | **진입 도우미.** QR·링크로 들어온 사람을 기기에 맞는 브라우저(안드로이드=크롬 / 아이폰=사파리)로 넘기고, 카카오톡 인앱브라우저에서 빠져나가게 함. **앱이 아니라 안내판 한 장** |
| `sw.js` | 서비스워커 — 오프라인 캐시 + 온라인 시 최신본 자동 반영(network-first). **임의 수정 금지** |
| `manifest.json` | 앱 설치 정보(이름·아이콘·색상) |
| `icon.png` | 앱 아이콘 512×512. `manifest.json` 이 참조 |
| `icon-192.png` `icon-512.png` | 구버전 호환용 아이콘 — 본체·`sw.js` 가 참조하므로 **삭제 금지** |
| `robots.txt` | 검색엔진 수집 차단 |
| `.nojekyll` | Jekyll 처리 우회. **삭제 시 백지(404) 발생 — 상주 필수** |

## 🔄 업데이트·버전 정책

- 배포 = **`index.html` 교체.** 서비스워커가 network-first라 접속만 하면 즉시 반영됩니다.
- 과거 버전 파일은 저장소에 따로 두지 않습니다 — 모든 이전 버전은 **Git 히스토리**에서 확인할 수 있습니다.
- 버전 표기는 앱 안 **6곳**(제목·상단 배지·푸터·저작권 카드·`APP_VERSION`·`DEPLOY_TAG`)이
**항상 일치**해야 합니다. 하나라도 어긋나면 배포판 식별이 깨집니다.
- 배포 전 검증: 인라인 스크립트 전수 구문검사 → 태그 수지 비교 →
헤드리스 실행(폭 360·390·412px × 글자배율 1.0·1.2·1.5, **pageerror 0**) → 눈으로 확인.
- **문서 무결성 6종**(2026-08-27 추가): `document.title` 비어 있지 않음 · `lang="ko"` 생존 ·
CSP 메타에 `connect-src 'none'` 생존 · `manifest.json`·`icon.png` 링크 생존 · `theme-color` 생존 ·
`body` 안에 `style` 태그 0개(런타임 생성분 제외).
**화면 그림만 같으면 통과가 아닙니다** — 화면은 멀쩡한데 문서 머리가 통째로 사라진 사고가 있었습니다.

## 📜 원칙

1. **통신 0건.** 외부로 보내는 코드를 넣지 않습니다. 음성인식(`SpeechRecognition`)은 음성을 구글 서버로 보내므로 **사용하지 않습니다.**
2. **단일 파일.** 외부 CSS·JS·이미지 링크 금지. 전부 인라인·data URI.
3. **원문 없으면 쓰지 않습니다.** 법령 조문·판례는 국가법령정보센터 원문을 직접 대조한 것만 싣습니다.
AI 검색 요약·블로그·언론 기사는 근거가 아닙니다.
사건번호를 확인하지 못한 판례는 앱 안에 **「사건번호 미확인」**으로 표시합니다.
4. **틀린 것을 지우지 않고 남깁니다.** 앱 「발자취」에 오류 이력을 남겨 검증이 가능하게 합니다.
5. **근거 등급을 표시합니다.** 법령·판례 원문과 내부 지침은 **등급이 다르며**, 앱에 그렇게 표시합니다.
