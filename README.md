# 🚔 교통수첩 T-Book

**교통외근 통합보조 — 외우지 말고, 필요할 때 펼쳐 보는 핸드북**

단일 HTML 파일 PWA. 모든 데이터는 본인 기기 안에서만 처리되며 외부 전송이 없습니다.

## 📲 설치

1. Chrome으로 **https://340patrolman.github.io/traffic-app/** 접속
2. 크롬 메뉴(⋮) → **"앱 설치"** (※ "홈 화면에 추가/바로가기"가 아니라 **앱 설치**)
3. 홈 화면 아이콘으로 실행 — 오프라인 동작 지원

기존 설치자가 아이콘·이름이 안 바뀌면: 기존 앱 제거 후 위 방법으로 재설치.

## ⚠️ 이용 안내

- 반드시 **정식 링크로 접속**해 사용하세요. 파일을 내려받아 여는 방식은 지원하지 않습니다(자동 업데이트·보안 보호가 작동하지 않음).
- 본 도구와 산출물은 **직무상 비밀**에 해당합니다. 무단 반출·제3자 공유·인터넷 공개를 금합니다.
- 업데이트는 접속만 하면 자동 반영됩니다.

## 📋 정보

- 구성: HTML + CSS + Vanilla JS 단일 파일 (서버·DB·외부 통신 없음)
- 저장: 사용자 설정·기록은 본인 기기(localStorage)에만 저장
- 문의: 제작자에게 직접
