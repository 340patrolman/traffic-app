# 🚔 교통수첩 T-Book

**교통외근 통합보조 — 외우지 말고, 필요할 때 펼쳐 보는 핸드북**

단일 HTML 파일 PWA. 모든 데이터는 본인 기기 안에서만 처리되며 외부 전송이 없습니다.

- 현재 배포 버전: **v19.14** (2026 정식배포판)
- 법령·범칙금 기준일: **2026.7** — 앱 화면 상단 배지에 항상 표시됩니다

## 📲 설치

1. Chrome으로 **https://340patrolman.github.io/traffic-app/** 접속
2. 크롬 메뉴(⋮) → **"앱 설치"** (※ "홈 화면에 추가/바로가기"가 아니라 **앱 설치**)
3. 홈 화면 아이콘으로 실행 — 오프라인 동작 지원

기존 설치자가 아이콘·이름이 안 바뀌면: 기존 앱 제거 후 위 방법으로 재설치.

## ⚠️ 이용 안내

- 반드시 **정식 링크로 접속**해 사용하세요. 파일을 내려받아 여는 방식은 지원하지 않습니다(자동 업데이트·보안 보호가 작동하지 않음).
- 앱에서 열람·생성한 **직무 관련 산출물의 무단 반출·제3자 공유·인터넷 공개를 금합니다.**
- 업데이트는 접속만 하면 자동 반영됩니다.
- 법령·범칙금은 **기준일(2026.7) 시점**의 내용입니다. 실제 처분·집행 시에는 국가법령정보센터 원문을 반드시 대조하십시오.

## 🔐 자료 보호 구조

이 저장소는 GitHub Pages 배포를 위해 **공개(public)** 로 운영됩니다. 자료 보호는 저장소 접근 제한이 아니라 **앱 내부 구조**로 구현되어 있습니다.

| 구분 | 처리 방식 |
|---|---|
| 법령·조문·범칙금 기준 등 **공개 정보** | 평문 수록 (국가법령정보센터 등 공개 출처 기반) |
| **직무 관련 상세 매뉴얼** | **AES-256-GCM 암호화** 상태로 파일에 내장. 복호화는 인가된 사용자가 기기 안에서 수행 |
| 진입 인증 | 정답을 **SHA-256 해시로만** 코드에 보관, 5회 오답 시 1시간 잠금 |
| 사용자 입력 | **입력 필드 0개.** 게시판·업로드 기능을 두지 않아 개인정보 유입 경로 자체가 없음 |
| 외부 전송 | 서버·DB·외부 API 호출 없음. 통신 0건 |
| 사용 기한 | **2027-02-20 자동 만료 + 기기 내 데이터 완전 소거** |

robots.txt로 검색엔진 수집을 차단하고 있습니다.

## 📁 파일 구성

| 파일 | 역할 |
|---|---|
| index.html | 앱 본체(현재 배포본). **이 파일 하나만 교체하면 업데이트 완료** |
| sw.js | 서비스워커 — 오프라인 캐시 + 온라인 시 최신본 자동 반영(network-first). 임의 수정 금지 |
| manifest.json | 앱 설치 정보(이름·아이콘·색상) |
| icon-192.png icon-512.png | 앱 아이콘 |
| icon.png | 구버전 호환용 아이콘 — 본체·sw.js가 참조하므로 **삭제 금지** |
| robots.txt | 검색엔진 수집 차단 |
| .nojekyll | Jekyll 처리 우회. **삭제 시 백지(404) 발생 — 상주 필수** |

## 🔄 업데이트·버전 정책

- 배포 = index.html 교체. 서비스워커가 network-first라 접속만 하면 즉시 반영됩니다.
- 과거 버전 파일은 저장소에 따로 두지 않습니다 — 모든 이전 버전은 **Git 히스토리(커밋 기록)** 에서 언제든 복원할 수 있습니다.
- 버전 표기는 <title> · 헤더 배지 · 앱 내 업데이트 이력 · 본 README 4곳을 함께 갱신합니다.

## 📋 정보

- 구성: HTML + CSS + Vanilla JS 단일 파일 (서버·DB·외부 통신 없음)
- 저장: 사용자 설정·기록은 본인 기기(localStorage)에만 저장
- 문의: 제작자에게 직접
