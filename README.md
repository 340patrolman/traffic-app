# 🚔 교통수첩 T-Book

**교통외근 통합보조 — 외우지 말고, 필요할 때 펼쳐 보는 핸드북**
*T-Book — a field handbook for traffic police*

단일 HTML 파일 PWA. 모든 데이터는 **본인 기기 안에서만** 처리되며 사건·서류·이름은 외부로 나가지 않습니다. 앱이 보내는 외부 요청은 사용자가 **홈 날씨를 켠 경우** 위치 좌표 2개를 open-meteo.com(무료 기상 API, 키 없음)에 보내는 것뿐이며 기본은 꺼짐입니다(v21.87). 음성 받아쓰기(🎙️)를 누를 때만은 **브라우저가** 음성을 음성인식 서버로 보냅니다(아래 「원칙」 1).

- 현재 배포 버전: **v23.33** (2026 전국 공용판) · 2026-09-28
- 법령·범칙금 기준일: **2026.9** (도로교통법 2026.7.1 시행본 · 시행령 별표6·7·8·10 · 시행규칙 별표28 2026.8.24 개정본 — 2026.9.27 국가법령정보센터 원문 재대조. 2027.2.25 시행 예정 신설 벌점은 「개정·신설」 카드에 별도) — 앱 화면 상단 배지에 표시됩니다. **기준일은 법령 원문을 대조한 날이고, 앱 판 번호·배포일과는 다릅니다**
- 판례 카드 **46건**(국가법령정보센터 사건번호 대조분만 수록) · 법령DB **53항목** · 자주 단속하는 **20항목 현장 해설** · 화면 **71개**(파일에 67개 + 실행 중 만드는 4개)

## 🔐 자료 보호 구조

이 저장소는 GitHub Pages 배포를 위해 **공개(public)** 로 운영됩니다.
자료 보호는 저장소 접근 제한이 아니라 **앱 내부 구조**로 구현되어 있습니다.

| 구분 | 처리 방식 |
|---|---|
| 법령·조문·판례 등 **공개 정보** | 평문 수록 (국가법령정보센터 등 공개 출처 원문 대조) |
| **직무 관련 상세 매뉴얼** | **AES-256-GCM** 암호화 상태로 파일에 내장. 복호화는 인가된 사용자가 **기기 안에서** 수행 |
| 진입 확인코드 | 정답을 **SHA-256 해시로만** 코드에 보관. 5회 오답 시 1시간 잠금 — 다만 **바른 코드는 잠금 중에도 통과**합니다(v21.66). ⚠️ **판정이 기기 안에서 이루어지는 「울타리」이지 금고가 아닙니다** — 공개 저장소라 마음먹은 사람은 우회할 수 있습니다. 내용을 실제로 막는 것은 위의 **암호화된 매뉴얼**뿐이며, 그 밖의 평문은 공개 저장소에서 누구나 볼 수 있다는 전제로 다룹니다 |
| **외부 전송** | 서버·DB 없음. 외부 요청은 **날씨 1건(선택, 기본 꺼짐)** — CSP `connect-src https://api.open-meteo.com` 한 도메인만 허용, 그 밖의 통신은 코드 수준에서 차단 |
| 개인정보 자동 삭제 | 입력란에 개인정보가 감지되면 **8시간 경과 시 자동 소거**, 백그라운드 60분 경과 시에도 소거 |
| 주민등록번호 | **저장 자체를 거부**합니다. 서류 작성란의 예시도 **마스킹**(`800101-1******`)이며 **브라우저 자동완성을 차단**합니다. 차량번호·전화번호는 경고를 띄웁니다 |
| 사용 기한 | **2027-02-20 자동 만료 → 화면 잠금.** 데이터는 보존되며, 잠금 화면에서 ①전량 백업 ②해제코드로 365일 연장 ③수동 삭제 중 선택 |

`robots.txt` 로 검색엔진 수집을 차단하고 있습니다.

### 입력란에 대한 정확한 설명

이 앱에는 **입력란이 있습니다** — 교대근무표·시간외수당 계산, 현장 관찰 메모,
내 서식·공문함(PDF·한글·워드·엑셀 첨부) 등이 입력을 받습니다.

**핵심은 「입력란이 없다」가 아니라 「입력한 것이 기기 밖으로 나가지 않는다」입니다.**

- 입력값은 전부 해당 기기의 `localStorage` / `IndexedDB` 에만 저장됩니다
- 서버로 보내는 코드가 **존재하지 않으며**, CSP `connect-src` 가 기상 API 한 도메인 외의 통신을 막고 있습니다(날씨를 켜면 좌표만, 끄면 그것도 없음)
- **현장 관찰 기록 창구에는 성명·차량번호·사진 입력란을 두지 않았습니다**
- **내 서식·공문함은 서식·공문 보관용**이며, 사건 자료 반입은 경고로 차단합니다
- 개인정보가 입력되면 **설정된 시간(기본 8시간) 경과 시 자동 삭제**됩니다

> 이전 README에 「입력 필드 0개」라고 적혀 있었으나 **사실과 달라 정정했습니다.**
> 실제로는 `input` 204개 · `textarea` 22개 · `select` 48개가 있습니다(v23.07 기준).
> 이 앱의 강점은 입력을 막는 것이 아니라 **입력한 것을 내보내지 않는 것**입니다.

## 📜 원칙

1. **앱이 보내는 통신은 날씨 1건뿐.** 그 밖에 외부로 보내는 코드를 넣지 않습니다. **음성 받아쓰기(🎙️)** 는 브라우저 음성인식(`SpeechRecognition`)을 씁니다 — 크롬에서는 **브라우저가** 음성을 구글 서버로 보내며 앱의 CSP 로 막을 수 없습니다. 정확도를 우선해 제작자가 이 경로를 쓰기로 정했습니다(2026-09-10). 받아쓰기 단추를 누를 때만 동작하고, 기기에는 글자로 된 결과만 남습니다. 민감한 내용은 받아쓰기로 말하지 말고 손으로 입력하십시오.
2. **본체 한 파일 + 같은 출처 파일만.** 외부 CSS·JS·폰트·CDN 링크 금지. 그림은 같은 저장소의 `dm/`, 지난 기록은 `hist.html`.
3. **원문 없으면 쓰지 않습니다.** 법령 조문·판례는 국가법령정보센터 원문을 직접 대조한 것만 싣습니다.
AI 검색 요약·블로그·언론 기사는 근거가 아닙니다.
사건번호를 확인하지 못한 판례는 앱 안에 **「사건번호 미확인」**으로 표시합니다.
4. **틀린 것을 지우지 않고 남깁니다.** 앱 「발자취」에 오류 이력을 남겨 검증이 가능하게 합니다.
5. **근거 등급을 표시합니다.** 법령·판례 원문과 내부 지침은 **등급이 다르며**, 앱에 그렇게 표시합니다.
